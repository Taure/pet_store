# Changelog

## [0.1.0] - 2026-02-14

### Added

- Pet schema with CRUD API endpoints (Nova + Cowboy)
- Kura integration for schemas, changesets, migrations
- rebar3_kura plugin for auto-generating migrations from schema diffs
- Common Test suites for API and migration testing
- CI with xref, dialyzer, erlfmt, and Common Test
- Release workflow with CHANGELOG-driven semver tagging
